# 网页转 PDF (Adobe 架构版) - 油猴脚本\n\n参考 **Adobe Acrobat** 官方谷歌扩展架构深度重构。定位于**真正通用（Universal）的高质量网页转 PDF 工具**，彻底根治多区块文档截断、只出1页纸、CSP 拦截样式错乱等全部结构性问题。\n\n---\n\n## 🚀 关键突破与彻底重构 (v2.5)\n\n1. **彻底攻克严格 CSP 拦截导致的「界面无样式、被挤压至左侧细条」严重缺陷**：\n   - **根因发现**：在 `ldcstore.com` 等现代严格安全站点上，服务端部署了严苛的 Content Security Policy：\n     `style-src-elem \x27self\x27; style-src-attr \x27none\x27;`\n     这导致浏览器底层**直接封杀并禁止执行任何前端内联 `<style>` 标签**！旧版通过 `document.createElement(\"style\")` 插入的样式被浏览器全部拒之门外，导致面板和悬浮球沦为无样式裸文本（宽度坍塌至左侧边缘垂直排列）。\n   - **重构为「CSP 免疫双模渲染引擎」**：\n     - 申请并引入 Tampermonkey 官方特权指令 `// @grant GM_addStyle`，**借助扩展级特权直接穿透 CSP 限制**；\n     - 采用 W3C 最新标准 Constructable StyleSheets (`CSSStyleSheet.replaceSync`)，无需向 DOM 插入 `<style>` 节点即可完成样式绑定，从协议层面杜绝 CSP 拦截；\n     - 双层防御体系确保在任何严苛安全站点（LDCStore、GitHub、金融系统）上界面绝不变形。\n2. **面板智能视口吸附保护**：\n   - 彻底修复当悬浮球位于屏幕左侧时面板可能被推入负坐标（超出屏幕左边界）的计算 Bug；\n   - 增加了视口边缘吸附防碰撞机制：当悬浮球靠左时面板自动向右侧展开，当悬浮球靠右时自动向左侧展开，强制固定 `360px` 标准宽度，绝不溢出屏幕。\n3. **彻底解决多 Section 页面截断与 Chromium「只出 1 张纸」Bug**：\n   - 默认全量克隆整个 `document.body`，完整保留多 Section、多卡片与表格；\n   - 强制清除 `height: 100%` 与 `overflow: hidden`，让所有内容顺畅排版至后续页面。\n\n---\n\n## 📁 目录文件\n\n- `webpage-to-pdf.user.js`：全新发布版油猴脚本 (v2.5.0)。\n- `test-page.html`：本地测试演示页面。\n- `README.md`：详细更新日志与技术架构说明。
