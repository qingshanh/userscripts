# 网页链接二维码生成器 (可移动 / 手机端适配)

一个轻量、优雅、完全自包含的油猴用户脚本（Tampermonkey / Violentmonkey / ScriptCat）。
在网页侧边生成一个可自由拖拽的悬浮二维码小图标，点击展开高清二维码，便于手机或其他移动设备扫码直接访问当前网页；再次点击二维码立即收起并恢复为原始小图标。

---

## 🌟 核心特性

1. **一键生成网页二维码**
   - 自动获取当前打开的网页完整地址（`window.location.href`），生成高对比度高清二维码。
   - 无论是手机相机、微信、支付宝还是各类浏览器扫码功能，均可瞬间秒扫直达。

2. **精巧的悬浮小图标**
   - 默认停靠于网页侧边（右下侧），现代化高质感微光阴影与圆润图标，不遮挡主体内容。
   - 支持高层级（`z-index: 2147483647`），避免被各大网站的固定导航栏遮挡。

3. **点击展开与再次点击收起**
   - **点击小图标**：平滑缩放展开二维码弹窗卡片。
   - **再次点击二维码**：直接点击二维码图片区域即可瞬间收起并恢复为原始小图标。
   - 同时支持点击右上角关闭按钮、点击背景半透明遮罩、或按下键盘 `Esc` 键快捷收起。

4. **全端自由拖拽与位置记忆**
   - **智能防误触**：内置 6px 位移判定阈值，拖拽移动绝不误触发点击展开；松手瞬间自动屏蔽误触。
   - **屏幕边界智能防越界**：自动约束在可见视口范围内，旋转屏幕或改变窗口尺寸时自动调整吸附，绝不丢失。
   - **自动持久化记忆**：拖动后自动保存位置（优先使用 `GM_setValue`，兼容 `localStorage`），下次打开网页或刷新页面仍然保持在用户习惯的位置。

5. **深度适配手机端触控浏览器**
   - 支持移动端单指滑动手势，配置 `touch-action: none` 防止拖拽时带动网页上下滚动。
   - 移动端小屏幕（宽度 $\le$ 640px）自适应居中弹窗，符合人体工学的大尺寸触控热区（$\ge$ 44px）。
   - 二维码以独立图像渲染，手机端支持长按识别二维码或保存图片。

6. **SPA 单页应用动态感知**
   - 针对 Bilibili、YouTube、小红书、微博、知乎等无刷新切换路由的现代 SPA 单页应用，每次展开时均动态读取最新 URL，无需手动刷新页面。
   - 面板内置「复制链接」与「重新获取链接」实用小工具。

7. **零外部网络依赖与 Shadow DOM 样式隔离**
   - 脚本内部完整打包轻量级 QRCode 引擎，**无需通过 `@require` 从外网 CDN 下载额外库**，断网或严格 CSP（内容安全策略）环境下 100% 稳定运行。
   - 核心 UI 挂载于独立的 `Shadow DOM (open)` 中，完全隔绝宿主网页的 CSS 污染，样式不会被 Bootstrap、Tailwind 或各类网页重置样式破坏。

---

## 📦 文件结构

- `url-to-qrcode.user.js`：完整的油猴脚本源文件（开箱即用，可直接安装至浏览器）。
- `test-page.html`：本地功能与交互验证测试页（双击即可在浏览器中预览测试）。
- `qrcode.min.js`：轻量压缩版 QR Code 生成内核源码。

## 🚀 安装方式

### 1. 桌面端浏览器 (Chrome / Edge / Firefox / Brave 等)
1. 确保浏览器已安装扩展：**Tampermonkey (篡改猴)** 或 **ScriptCat (脚本猫)** / **Violentmonkey (暴力猴)**。
2. 打开 Tampermonkey 的「添加新脚本」编辑器页面。
3. 全选复制 `url-to-qrcode.user.js` 的所有代码，粘贴覆盖后按 `Ctrl + S` 保存。
4. 刷新任意网页即可看到右侧的悬浮小图标。

### 2. 手机端浏览器 (Android / iOS)
- **Android (Via 浏览器 / X 浏览器 / Kiwi / Firefox 移动版)**：
  - **Via 浏览器**：设置 -> 脚本 -> 添加脚本 -> 域名匹配填 `*` -> 粘贴 `url-to-qrcode.user.js` 代码 -> 保存。
  - **Kiwi / Firefox 移动版**：安装 Tampermonkey 扩展后，按桌面端方式导入脚本即可。
- **iOS (Safari)**：
  - 安装 **Userscripts** 或 **Stay** 扩展，将 `url-to-qrcode.user.js` 导入即可在 Safari 移动端使用。

## 🛠️ 油猴菜单集成

在浏览器扩展图标的油猴下拉菜单中，提供了快捷操作：
- **生成当前网页二维码**：直接唤起二维码面板。
- **重置悬浮图标位置**：一键将图标重置回默认的右下角停靠点。

## 🧪 本地测试验证

在本项目目录下，直接用浏览器打开 `test-page.html`：
1. 测试鼠标或手机单指拖拽移动悬浮小图标。
2. 点击悬浮小图标，确认二维码正常展开。
3. 点击展开后的二维码图片，确认二维码立即收起并恢复为悬浮小图标。
4. 点击页面中的「切换路由」按钮，再打开二维码，确认已自动更新为最新地址。
